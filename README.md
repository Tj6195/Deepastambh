# Deepstambh: a fixed point for your career decisions
1. Install Python 3.9 or newer and open a terminal in this folder.
2. (Optional) Create a virtual environment: `python -m venv venv`, then activate it.
3. Install the requirement: `pip install -r requirements.txt`
4. Start the app: `streamlit run app.py`
5. Open http://localhost:8501 in your browser. Keep logo.png in this folder to show the logo.
